Models

Five on-chain models, each served from its own Internet Computer canister. Switch between them from the dropdown at the top of the studio. They are listed here lightest to largest — the same order as the Canisters page — which is roughly cheapest/fastest to most capable.

Gemma-3-270M Smallest

Google's Gemma-3-270M — the smallest and cheapest model that runs on-chain, and the fastest (the most tokens-per-call and lowest cycle cost of any ICGPT model). Great for quick, simple tasks and demos. As a 270M model it is unreliable for precise instruction-following, negation, or secret-keeping — for those, prefer a Qwen3 model or LFM2.5. It uses Gemma's own chat template (no system role, no thinking block).

  • File: gemma-3-270m-it-Q8_0.gguf (q8_0 quantized)
  • Context: 4K tokens (~3K words)
  • Model card: unsloth/gemma-3-270m-it-GGUF on HuggingFace

Qwen3-0.6B Default

Our recommended default — a state-of-the-art small model run in non-thinking mode for clean, direct answers over multi-turn conversations. A hybrid thinking model, so you can turn thinking on when a task needs step-by-step reasoning. It runs with a large ~12,000-word context window entirely in-canister.

  • File: Qwen3-0.6B-Q8_0.gguf (q8_0 quantized)
  • Context: 16K tokens (~12K words)
  • Model card: Qwen/Qwen3-0.6B-GGUF on HuggingFace

Qwen2.5-0.5B-Instruct

The previous default — an excellent, lightweight instruct model, kept available for comparison. It uses the classic chat template (no thinking block).

  • File: qwen2.5-0.5b-instruct-q8_0.gguf (q8_0 quantized)
  • Context: 16K tokens (~12K words)
  • Model card: Qwen/Qwen2.5-0.5B-Instruct-GGUF on HuggingFace

LFM2.5-1.2B New

Liquid AI's LFM2.5-1.2B — a faster, cheaper alternative to Qwen3-1.7B at similar quality. It is a hybrid architecture (a mix of grouped-query attention and short-convolution blocks), so it keeps a small KV cache and generates more tokens per call at about half the cycles of the 1.7B — while still passing tasks that need precise instruction-following and negation. Uses the ChatML template.

  • File: LFM2.5-1.2B-Instruct-Q4_K_M.gguf (Q4_K_M quantized)
  • Context: 4K tokens (~3K words)
  • Model card: LiquidAI/LFM2.5-1.2B-Instruct-GGUF on HuggingFace

Qwen3-1.7B Most capable

The largest, most capable model here — best for tasks needing precise instruction-following, negation, or keeping a secret. Also a hybrid thinking model. Being bigger, it generates fewer tokens per update call, so replies cost more cycles and stream a little slower — often LFM2.5 gets you the same quality for less.

  • File: Qwen3-1.7B-Q4_K_M.gguf (Q4_K_M quantized)
  • Context: 16K tokens (~12K words)
  • Model card: unsloth/Qwen3-1.7B-GGUF on HuggingFace

How they're tuned

Each model is quantized (q8_0, or Q4_K_M for the larger two) with a quantized KV cache and a small batch size, which keeps its context inside the canister's memory budget. The Internet Computer's per-message instruction limit caps how many tokens a single call generates, so replies are produced across several update calls — which is why generation streams in batches, and why a bigger model (fewer tokens per call) costs more per reply. The Prompt Cost Lab lets you measure that trade-off exactly and pick the cheapest model that still passes your task.
