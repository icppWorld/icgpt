Models

Two on-chain models, each served from its own Internet Computer canister. Switch between them from the dropdown at the top of the studio.

Qwen3-0.6B Default

Our recommended default — a state-of-the-art small model run in non-thinking mode for clean, direct answers over multi-turn conversations. It runs with a large ~12,000-word context window entirely in-canister.

  • File: Qwen3-0.6B-Q8_0.gguf (q8_0 quantized)
  • Context: 16K tokens (~12K words)
  • Model card: Qwen/Qwen3-0.6B-GGUF on HuggingFace

Qwen2.5-0.5B-Instruct

The previous default — an excellent, lightweight instruct model, kept available for comparison. It uses the classic chat template (no thinking block).

  • File: qwen2.5-0.5b-instruct-q8_0.gguf (q8_0 quantized)
  • Context: 16K tokens (~12K words)
  • Model card: Qwen/Qwen2.5-0.5B-Instruct-GGUF on HuggingFace

How they're tuned

Both models are quantized to q8_0 with a quantized KV cache and a small batch size, which keeps a large context inside the canister's memory budget. The Internet Computer's per-message instruction limit caps how many tokens a single call generates, so replies are produced across several update calls — which is why generation streams in batches.

Switching models starts a new conversation. A chat is pinned to one model's canister (where its prompt cache lives), so it can't continue on a different model. See How it works.
